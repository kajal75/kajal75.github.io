01 / About

Backend-focused, production-minded.

I'm a PHP developer based in Noida, India, working mostly on the server side: designing REST APIs, connecting third-party platforms and keeping MySQL databases fast as data and traffic grow.

At Empowered Margins, I build Laravel REST API integrations and cron jobs that keep candidate, exam-registration and enrollment data in sync between WebAssessor and YourMembership. This replaced manual data entry across both systems. I also deliver features and data integrations for the CARE AMS and LMS platforms and handle production releases.

Much of my work is on production problems: cutting dashboard load from thousands of queries to under a hundred, closing race conditions that created duplicate orders, hardening OAuth single sign-on, and making payment, email and certificate flows reliable under real traffic.

Before that, at Adwiti Technocrats, I built CodeIgniter modules for insurance and travel applications, including policy management, booking flows, JSON APIs consumed by frontend teams and third parties, and MySQL schemas designed for concurrent multi-user load.

I hold an MCA from Meerut Institute of Engineering and Technology and a BCA from Chaudhary Charan Singh University.

06 / Highlights

Engineering highlights

Real production challenges, how I solved them, and what changed.

Database performance

Admin dashboard optimization

Challenge
The admin dashboard took over a minute to load because of thousands of repeated database queries.
My solution
Removed N+1 queries, combined monthly lookups into single aggregate queries and added the missing indexes.
Result
About 3,251 → 99 queries and about 74 s → 22 s per load, with identical figures.
Payment integration

Paytring payment gateway

Challenge
Indian customers needed a local payment option billed in INR, with no risk of an order being marked paid twice or without a payment.
My solution
Integrated Paytring checkout with live currency conversion. Each payment callback is verified against the stored charge, and a scheduled job completes payments that were still processing.
Result
A verified, replay-safe INR payment option alongside the existing gateways.
Security · SSO

OAuth 2.0 single sign-on

Challenge
Bots were abusing the sign-in endpoint as an open redirect, and some users got stuck in login loops between AMS and LMS.
My solution
Restricted redirects to registered addresses, re-validated clients before issuing codes, and added single logout plus stale-session re-authentication.
Result
Closed the redirect weakness, ended the login loops, and one logout now signs users out of both platforms.
Data synchronization

AMS ↔ LMS enrollment sync

Challenge
Registrations, cancellations, deletions and expiry changes made in AMS were not reliably reflected in the LMS.
My solution
Built sync services and APIs for each change, reused one course enrollment across linked events, and archived old progress when learners re-enroll after expiry.
Result
Both systems stay consistent automatically, without duplicate enrollments for linked events.
Production reliability

Orders, invoices and certificates

Challenge
Double-submitted checkouts created duplicate orders, simultaneous checkouts collided on invoice numbers, and failed certificate regenerations left broken links.
My solution
Added one-time checkout locks and collision-safe invoice numbering, and changed certificate regeneration to replace the old file only after the new one is confirmed.
Result
Every order gets one invoice, and learners always keep a working certificate.
Background processing

PowerPoint rendering pipeline

Challenge
Instructor presentations depended on an embedded third-party viewer, with limited control over animations and loading speed.
My solution
Built a queued pipeline that renders uploaded decks into slides and animation clips, reports live progress, and serves files from AWS S3 / CloudFront with preloading.
Result
Presentations play in the browser with their animations, and admins see conversion status for every upload.
