# Kajal Thakur · Portfolio

Static portfolio site built with HTML, CSS and vanilla JavaScript. No build step.

```
index.html            page content
css/style.css         styles
js/main.js            nav menu, scroll spy, reveal animations, copy-email
assets/favicon.svg
assets/Kajal_Thakur_PHP_Laravel_Developer.pdf   resume (Download Resume button)
```

## Run locally
Double-click `index.html`, or serve the folder:

    python -m http.server 8000      # then open http://localhost:8000

## Before publishing
- Search `index.html` for `PLACEHOLDER` and fill in or delete each one.
- To update the resume, replace `assets/Kajal_Thakur_PHP_Laravel_Developer.pdf` (keep the same file name).

## Publish
**GitHub Pages:** push these files to a repo (for example `kajal75.github.io`), then go to
Settings → Pages → Deploy from branch → `main` / root.

**Netlify:** go to app.netlify.com → Add new site → Deploy manually, then drag this folder onto the page.
